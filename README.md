## Galactic Gunners! 

Galactic Gunners is a 3D first person shooter in which the player uses attachments on a physical controller in order to change guns in the game. The attachments will turn the controller from a blaster, to a zinger, disruptor or to a vaporizer. To complete the game the player will have to fight hordes of aliens, and complete the objectives. Objectives include delivering an item and destroying an object within a time limit. Every few objectives completed the aliens will get stronger and harder to defeat. Some aliens will be resistant to gun types and will take less damage. This game will use the Makey-Makey and the Nintendo Switch Joycons to create the controller. 

This game was a uni project for my Gaming Hardware class! Game Link: https://katiem1013.itch.io/galactic-gunners

## Technologies

- Unity
- The Makey-Makey
- Nintendo Switch Controlllers

## Features

- A custom gun controller that when changed in real life changes the gun in game
- Multiple different objects that require the changing of guns
- Five enemy types that have their own weakness and strengths
- Gyro controls to aim the weapons in game for better immersion

## The Process

This game was a university third year project. The inspiration for this game came from wanting to make a fully immersive game and controller. I originally was going to use the Wii controllers but ended up switching to the Switch controllers a few months in. I combined this with the Makey-Makey to control the attachements for the gun. The game was completely coded in Unity and was made over a 6 months period from designing to hand in.
